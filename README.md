# Takumoto — ClassKeeper

Статический сайт-помощник для класса. Следит за тишиной, начисляет баллы, ведёт рейтинг команд и раздаёт купоны-бонусы.

Сайт находится в папке [`classkeeper/`](./classkeeper/). Откройте `classkeeper/index.html` в браузере.

## Скачать

Архив с сайтом: [classkeeper.zip](https://github.com/TAKUMOTOSAN/Takumoto/releases/latest/download/classkeeper.zip)

Или скачайте весь репозиторий:
```bash
git clone https://github.com/TAKUMOTOSAN/Takumoto.git
```
